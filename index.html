01 / Mathematical Optimization

Search. Pack. Verify.

Combinatorial problems where the feasible set is huge, the constraints are hard, and a heuristic that cannot prove feasibility is useless.

[ SA-01 ]

Simulated Annealing

  • Move operators chosen for the constraint structure
  • Cooling schedules tuned per instance, not copied
  • Penalty weights adapted to keep the walk near feasibility
[ SAT-02 ]

SAT-Style Collision Detection

  • Separating-axis tests for convex polygon overlap
  • Incremental collision checks on single-move updates
  • Exact integer geometry where floating point lies
[ PACK-03 ]

Squares in Squares Packing

  • Placing squares inside a bounding square with no overlap
  • Feasibility-first construction, then local refinement
  • Layout scoring by wasted area and boundary slack
02 / Transformer Architectures

From Scratch.

Attention models written without high-level wrappers, so every normalization, head layout, and parameter count is a decision I made and can defend.

[ TF-01 ]

Block Design

  • Pre-LayerNorm residual blocks for stable deep stacks
  • Grouped-Query Attention to cut KV cache and bandwidth
  • Explicit tensor shapes at every projection
[ TF-02 ]

Parameter Budgets

  • Fixed parameter ceilings set before the first run
  • Width, depth, and KV-head ratio traded against each other
  • Per-component parameter accounting in the config
[ TF-03 ]

Gradient Dynamics

  • Per-layer gradient norm tracking during training
  • Learning-rate warmup and decay matched to depth
  • Diagnosing loss spikes against activation statistics
03 / Custom Hardware Benches

Unthrottled.

Compute machines built to hold peak clocks under sustained load, and logic boards repaired at the component level.

[ HW-01 ]

Logic Board Micro-Soldering

  • Fine-pitch rework and component replacement
  • Power rail tracing before any part is swapped
  • Fault isolation with multimeter and scope
[ HW-02 ]

Thermal Dissipation

  • Airflow path designed around the heat sources
  • Sustained-load clock logs used to judge cooling
  • Heatsink and interface material selected per part
[ HW-03 ]

Unthrottled x86 Compute

  • Power limits and boost behavior set for sustained load
  • Memory and storage configured for the workload
  • Stability verified under long-duration stress runs
