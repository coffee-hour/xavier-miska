# xavier-miska

Personal static site for Xavier Miska, Hardware Builder & Systems Architect.

A single self-contained `index.html` with inline CSS and vanilla JS. No build step.

## Deploy to Cloudflare Pages (1-click)

1. Log in to the Cloudflare dashboard and go to Workers & Pages.
2. Click Create application, then the Pages tab, then Connect to Git.
3. Select this GitHub repository (coffee-hour/xavier-miska) and authorize Cloudflare if prompted.
4. Set the build configuration:
   - Framework preset: None
   - Build command: (leave empty)
   - Build output directory: .
5. Click Save and Deploy.

Every push to `main` redeploys automatically.
